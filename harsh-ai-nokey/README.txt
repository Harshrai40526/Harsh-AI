Deploy (sabse aasan, 1 minute):
  1. https://app.netlify.com/drop kholo
  2. Is zip ko extract karke andar wala folder (jisme index.html hai) drag-drop kar do.
  3. Link mil jayega. Bas.

GitHub se deploy karna ho:
  - Repo ki saari purani files delete karo (api, netlify, public, vercel.json, netlify.toml sab).
  - Sirf index.html repo ke ROOT me daalo.
  - Netlify/Vercel me koi setting ya environment variable nahi chahiye.
